# Бот для продажи цифровых продуктов

Telegram-бот по образцу NIKSHEN_BOT: меню из любых разделов, бесплатные гайды, квиз
«С чего начать?», инструкции, продажа платных продуктов с автоматической выдачей.

## Что умеет

**Для покупателя**
- 🧭 Меню и разделы любой вложенности — всё собирается в `content.yaml`, без кода
- 🎁 Бесплатные гайды: приходят в чат сразу по нажатию кнопки
- ❓ Квиз «С чего начать?» — ведёт человека к подходящему продукту
- 🛍 Карточки платных продуктов (текст, цена, обложка)
- 💳 Оплата на выбор: картой через Tribute или переводом на карту с чеком (также умеет звёзды и ЮKassa)
- ⚡ Автоматическая выдача сразу после оплаты: файл, ссылка, текст или одноразовое приглашение в закрытый канал
- 📦 «Мои покупки» — забрать купленное ещё раз в любой момент
- 🔗 Прямые ссылки для постов и рилсов: `https://t.me/ИМЯ_БОТА?start=g01_first` — гайд придёт сразу

**Для тебя**
- 💰 Уведомление о каждой покупке: что купили, за сколько, кто
- 📊 `/stats` — сколько людей запустили бота, сколько забрали каждый бесплатный гайд, сколько купили, выручка
- ✏️ Все экраны, кнопки, тексты и продукты в одном файле `content.yaml`, правки применяются командой `/reload` без перезапуска
- 🧾 Переводы на карту: чек покупателя приходит тебе с кнопками «выдать / отклонить», свой чек из «Мой налог» отправляешь ответом
- ↩️ `/refund` — возврат звёзд
- 🛡 Защита: продукт не выдаётся дважды за одну оплату, чужой заказ не оплатить, подменённую сумму бот отклонит

## Запуск за 6 шагов

### 1. Создай бота
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...` — это ключ от бота, никому его не показывай.

Там же можно оформить бота: `/setuserpic` (аватар), `/setdescription` (текст до нажатия «Старт»), `/setabouttext` (описание в профиле).

### 2. Узнай свой Telegram ID
Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт число. Это твой ID администратора.

### 3. Установи Python и зависимости
Нужен Python 3.11 или новее.
```bash
cd sales-bot
python3 -m venv .venv
source .venv/bin/activate        # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 4. Заполни настройки
Скопируй `.env.example` в `.env` и впиши токен и свой ID:
```
BOT_TOKEN=1234567890:AAH...
ADMIN_IDS=123456789
PAYMENT_METHODS=tribute,transfer
TRANSFER_DETAILS="Карта: 2200 0000 0000 0000\nПолучатель: Имя Ф."
```
Подробно про оплату — в разделе «Оплата» ниже.

### 5. Наполни бота
Открой `content.yaml`. Там уже собрана структура как у NIKSHEN_BOT: меню, бесплатные гайды, квиз, инструкции, вопросы, связь. Продукты, ссылки и `@ник` — заглушки, замени их на свои. Как устроены экраны — ниже.

### 6. Запусти
```bash
python -m bot
```
Открой своего бота в Telegram и нажми «Старт». Напиши ему один раз со своего аккаунта — иначе бот не сможет присылать тебе уведомления о покупках.

## Как устроены экраны

Бот — это набор экранов. Экран = текст + кнопки. `start` — главное меню.

```yaml
screens:
  start:
    text: |
      Здравствуйте, {name} 🤍
    buttons:
      - {text: "🎁 Бесплатно", screen: free}                    # одна кнопка в ряд
      - [{text: "📖 Инструкции", screen: instructions},
         {text: "❓ Вопросы", screen: faq}]                     # две кнопки в ряд
      - {text: "📘 Нейросети с нуля", product: guide}           # карточка продукта
      - {text: "🌐 Сайт", url: "https://..."}                   # внешняя ссылка ↗
      - {text: "📦 Мои покупки", my: true}
```

Чтобы добавить раздел: придумай id (латиницей), опиши экран в `screens` и поставь на него кнопку с `screen: id` в нужном месте. Не забудь кнопку «⬅️ Назад» внутри нового экрана.

Бесплатный продукт — это продукт с `free: true`: по кнопке он сразу приходит в чат, а бот считает, сколько людей его забрали.

## Бесплатные гайды

В боте 5 гайдов-PDF. Каждый решает одну задачу и в конце ведёт к платному продукту:

| № | Гайд | Для кого | Ведёт к |
|---|---|---|---|
| 01 | Первые 3 минуты с нейросетью | ещё не пользовался(ась) | гайд 02, «Нейросети с нуля» |
| 02 | Почему нейросеть отвечает водой | пробовал(а) и разочаровался(ась) | гайд 03, «Нейросети с нуля» |
| 03 | Ответ не тот: 10 поправок | ответы есть, но не те | «Библиотека запросов» |
| 04 | Бюджет поездки за 20 минут | планирует поездку | «Нейросети с нуля» |
| 05 | Неловкое сообщение за 5 минут | надо отказать, напомнить, попросить | «Нейросети с нуля», «Библиотека запросов» |

После каждого гайда бот сам присылает короткое сообщение с кнопками: следующий гайд и платный продукт (`followup` в `content.yaml`).

### Как поправить текст гайда
1. Открой нужный файл в `guides/` — это обычный текст (Markdown).
2. Поправь. Специальные блоки выглядят так:
   ```
   :::prompt Скопируй и подставь своё
   Текст запроса. [Места для своих данных] в квадратных скобках — подсветятся.
   :::
   ```
   Есть блоки `prompt`, `result`, `why`, `check`, `warn`, `note`, `bad`, `good`, `author`, `next`.
3. Пересобери PDF (нужен установленный Google Chrome):
   ```bash
   pip install markdown
   python guides/build.py
   ```
   Готовые PDF окажутся в `products/`. Отправь боту `/reload`.

Шрифты (Cormorant Garamond и Manrope, лицензия SIL Open Font) лежат в `guides/fonts/`, интернет для сборки не нужен.

## Рассылка

1. Напиши боту сообщение, как обычно: текст, фото, видео, файл.
2. Ответь на него командой `/broadcast`. Если нужна кнопка на продукт или экран — `/broadcast guide`.
3. Бот покажет превью и спросит, кому отправить:
   - **Всем**
   - **Кто не купил** — главный сегмент для продаж
   - **Кто купил** — для новостей и новых продуктов
4. После отправки придёт отчёт: сколько доставлено и сколько человек заблокировали бота. Заблокировавших бот исключает из следующих рассылок автоматически.

⚠️ Не присылай рассылки часто. Если люди начнут жаловаться на спам, Telegram может ограничить бота. Одно-два сообщения в неделю по делу — безопасный ритм.

## Прогрев

Серия сообщений после **первого** бесплатного гайда — задаётся в `content.yaml` в разделе `nurture`. Сейчас там три шага:

| Когда | Что | Кому |
|---|---|---|
| через 1 день | «Как успехи?» + гайд 03 и «напиши мне» | всем |
| через 3 дня | «Нейросети с нуля» | кто ещё не купил его |
| через 6 дней | «Библиотека запросов» | кто ещё не купил её |

- Сообщения уходят только днём: `nurture_hours` в `content.yaml` (сейчас 10–21) по часовому поясу `TIMEZONE` из `.env`.
- Каждый шаг человек получает один раз.
- Новый шаг, добавленный позже, получат только те, кто забрал гайд недавно, — старую базу он не заспамит.
- Сколько людей получили каждый шаг — видно в `/stats`.

## Оплата

Способы включаются в `.env` через запятую: `PAYMENT_METHODS=tribute,transfer`. Если способов несколько, покупатель выбирает сам.

| Способ | Как платит покупатель | Кто выдаёт продукт | Что нужно от тебя |
|---|---|---|---|
| `tribute` | картой на странице Tribute | Tribute сразу после оплаты, бот — тоже, если подключены уведомления | продукты в Tribute |
| `transfer` | переводом на карту или по СБП, потом присылает скриншот чека | бот — после твоего подтверждения | проверять поступления |
| `stars` | звёздами Telegram | бот сразу | ничего |
| `yookassa` | картой или СБП | бот сразу | договор с ЮKassa |

### Перевод на карту

1. Впиши реквизиты в `.env`:
   ```
   TRANSFER_DETAILS="Карта: 2200 0000 0000 0000\nПолучатель: Имя Ф.\nИли по СБП: +7 000 000-00-00, банк …"
   ```
   `\n` — перенос строки. Реквизиты хранятся только на сервере и в git не попадают.
2. Покупатель выбирает «Переводом на карту» → видит сумму, реквизиты и номер заказа → переводит → присылает боту скриншот или файл чека.
3. Тебе приходит этот чек с кнопками:
   - **✅ Деньги пришли — выдать** — бот сразу отправит покупателю продукт.
   - **❌ Отклонить** — бот напишет покупателю, что перевод не нашёлся, и предложит связаться с тобой.
4. **Чек для покупателя.** Ответь на сообщение с его чеком своим чеком из «Мой налог» — фото, файлом или ссылкой. Бот перешлёт его покупателю.

Сколько переводов ждут проверки — видно в `/stats`. Покупатель может отменить заказ, пока не прислал чек.

⚠️ **Налоги и банк — насколько я знаю, уточни у бухгалтера.** Если ты самозанятая, на каждую оплату нужно пробить чек в «Мой налог». Частые переводы от незнакомых людей на личную карту без оформленной самозанятости банк может посчитать подозрительными.

### Tribute

**1. Создай продукты в Tribute.** В кабинете автора Tribute — цифровой продукт для каждого платного продукта бота:
- содержимое — тот же PDF (Tribute сам пришлёт его покупателю);
- цена — в рублях, такая же, как `price_rub` в `content.yaml`.

**2. Впиши ссылки в `content.yaml`** — у каждого платного продукта:
```yaml
tribute_url: https://web.tribute.tg/p/XXXX
```
Этого уже достаточно, чтобы принимать оплату. Но без следующего шага бот не узнаёт о покупках: они не попадут в «Мои покупки» и статистику, а прогрев продолжит предлагать купленное.

**3. Уведомления о покупках (по желанию, но советую).** Tribute присылает уведомление о каждой покупке на твой адрес. Для этого нужен домен (подойдёт и поддомен вида `bot.твойсайт.ru`), направленный на сервер.

- В `.env`: `TRIBUTE_API_KEY=` — ключ из раздела API в кабинете Tribute.
- У каждого продукта в `content.yaml`: `tribute_product_id: 123456` — номер продукта в Tribute.
- Открой адрес наружу с HTTPS через Caddy (сертификат он получит сам):
  ```bash
  sudo apt install -y caddy
  echo 'bot.твойсайт.ru {
    reverse_proxy /tribute/webhook 127.0.0.1:8080
  }' | sudo tee /etc/caddy/Caddyfile
  sudo systemctl reload caddy
  ```
- В кабинете Tribute укажи адрес для уведомлений: `https://bot.твойсайт.ru/tribute/webhook`.
- Перезапусти бота: `sudo systemctl restart sales-bot`.

Бот проверяет подпись каждого уведомления ключом API. Повторные уведомления не создают дублей, а возвраты в Tribute отмечаются в заказе, и тебе приходит сообщение.

**Честно о том, что не проверено.** Интеграцию я собрал по документации Tribute и открытому примеру: [вебхуки](https://wiki.tribute.tg/for-content-creators/api-documentation/webhooks), [интеграция цифровых товаров](https://wiki.tribute.tg/ru/for-content-creators/digital-product/api-integration), [веб-оплата](https://wiki.tribute.tg/ru/for-content-creators/digital-product/web-oplata). На настоящем аккаунте Tribute она не проверялась. Не проверено, приходит ли ID покупателя при оплате картой через веб-страницу. Если не придёт, бот сообщит тебе о покупке, а продукт всё равно выдаст Tribute. Комиссию Tribute и сроки выплат смотри в его кабинете.

### Звёзды и ЮKassa

Остались в боте как запасные способы: `PAYMENT_METHODS=stars` или `yookassa`. Для ЮKassa заполни `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` из личного кабинета. Бот сам проверяет оплату каждые 30 секунд. Для звёзд Telegram требует команду `/paysupport` — она есть.

## Продажа доступа в закрытый канал
1. Создай приватный канал и добавь бота администратором с правом **«Пригласительные ссылки»**.
2. Узнай ID канала: перешли любой пост из канала боту [@userinfobot](https://t.me/userinfobot) — ID начинается с `-100`.
3. В `content.yaml` у продукта укажи:
   ```yaml
   delivery:
     type: channel
     value: "-1001234567890"
   ```
Каждый покупатель получит одноразовую ссылку, которую нельзя переслать другу.

⚠️ При возврате денег бот **не удаляет** человека из канала автоматически — это нужно сделать вручную.

## Запуск на сервере (круглосуточно)

Пока бот запущен на твоём компьютере, он работает, только когда компьютер включён. Для продаж нужен сервер.

**Какой сервер:** любой VPS с Ubuntu 22.04 или 24.04, 1 ГБ памяти хватит с запасом. Боту нужен доступ к api.telegram.org, а для ЮKassa — к api.yookassa.ru.

### Сервер в Timeweb Cloud

1. В [Timeweb Cloud](https://timeweb.cloud) создай облачный сервер:
   - ОС — **Ubuntu 24.04**;
   - самая простая конфигурация — боту хватит 1 ГБ памяти;
   - регион — Россия.
2. Когда сервер создастся, в панели будут его IP-адрес и пароль root. Подключиться можно из терминала: `ssh root@IP-адрес`. Или через консоль прямо в панели Timeweb.
3. Выполни команду установки ниже. В конце она сама проверит, открывается ли с сервера Telegram.

Точные названия кнопок в панели Timeweb я не вижу и не проверял — ориентируйся по смыслу.

**Если Telegram с сервера не открывается.** В 2025 году в России ограничивали работу Telegram; как с этим сейчас, я точно не знаю — проверка покажет. Если связи нет, бот может работать через прокси: впиши его в `.env` и перезапусти бота.
```
TELEGRAM_PROXY=socks5://логин:пароль@хост:порт
```
Через прокси идёт только связь с Telegram. Tribute, ЮKassa и база работают напрямую.

Проверить связь ещё раз: `sudo bash /opt/moy-den/sales-bot/deploy/check.sh`.

**Почему российский сервер — хороший выбор.** Насколько я знаю, закон о персональных данных (152-ФЗ) требует хранить базу данных россиян на территории России. А бот хранит Telegram ID, имена и покупки. Поэтому российский сервер с прокси для Telegram лучше, чем зарубежный сервер. Оформление самих персональных данных (политика обработки, уведомление Роскомнадзора) — вопрос к юристу.

**Установка — одна команда** (подключившись к серверу по SSH):
```bash
curl -fsSL https://raw.githubusercontent.com/yaremchykyuliya/moy-den/main/sales-bot/deploy/install.sh | sudo bash
```
Скрипт поставит всё нужное, создаст отдельного пользователя `salesbot`, настроит автозапуск и ночную копию базы. В конце он подскажет три шага:

1. Заполнить настройки: `sudo nano /opt/moy-den/sales-bot/.env`
2. Загрузить платные PDF с компьютера:
   ```bash
   scp neyroseti-s-nulya.pdf biblioteka-zaprosov.pdf root@АДРЕС_СЕРВЕРА:/opt/moy-den/sales-bot/products/paid/
   sudo chown salesbot:salesbot /opt/moy-den/sales-bot/products/paid/*
   ```
3. Запустить: `sudo systemctl start sales-bot`

**Полезные команды**

| Что | Команда |
|---|---|
| Смотреть, что делает бот | `sudo journalctl -u sales-bot -f` |
| Проверить связь с Telegram | `sudo bash /opt/moy-den/sales-bot/deploy/check.sh` |
| Перезапустить | `sudo systemctl restart sales-bot` |
| Обновить до новой версии | `sudo bash /opt/moy-den/sales-bot/deploy/update.sh` |
| Поправить тексты | `sudo nano /opt/moy-den/sales-bot/content.yaml`, потом `/reload` в боте |

Копии базы с покупками лежат в `/opt/moy-den/sales-bot/backups/`, хранятся последние 14 дней.

⚠️ Скрипт берёт код из ветки `main`. Пока изменения не слиты в `main`, запускай так: `curl … | sudo BRANCH=имя-ветки bash` — ссылку тоже поменяй с `main` на имя ветки.
