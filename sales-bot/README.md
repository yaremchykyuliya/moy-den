# Бот для продажи цифровых продуктов

Telegram-бот по образцу NIKSHEN_BOT: меню из любых разделов, бесплатные гайды, квиз
«С чего начать?», инструкции, продажа платных продуктов с автоматической выдачей.

## Что умеет

**Для покупателя**
- 🧭 Меню и разделы любой вложенности — всё собирается в `content.yaml`, без кода
- 🎁 Бесплатные гайды: приходят в чат сразу по нажатию кнопки
- ❓ Квиз «С чего начать?» — ведёт человека к подходящему продукту
- 🛍 Карточки платных продуктов (текст, цена, обложка)
- 💳 Оплата прямо в Telegram: звёзды или рубли через ЮKassa
- ⚡ Автоматическая выдача сразу после оплаты: файл, ссылка, текст или одноразовое приглашение в закрытый канал
- 📦 «Мои покупки» — забрать купленное ещё раз в любой момент
- 🔗 Прямые ссылки для постов и рилсов: `https://t.me/ИМЯ_БОТА?start=free_start` — гайд придёт сразу

**Для тебя**
- 💰 Уведомление о каждой покупке: что купили, за сколько, кто
- 📊 `/stats` — сколько людей запустили бота, сколько забрали каждый бесплатный гайд, сколько купили, выручка
- ✏️ Все экраны, кнопки, тексты и продукты в одном файле `content.yaml`, правки применяются командой `/reload` без перезапуска
- ↩️ `/refund` — возврат звёзд
- 🛡 Защита: продукт не выдаётся дважды за одну оплату, чужой заказ не оплатить, подменённую сумму бот отклонит

## Запуск за 6 шагов

### 1. Создай бота
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...` — это ключ от бота, никому его не показывай.

Там же можно оформить бота: `/setuserpic` (аватар), `/setdescription` (текст до нажатия «Старт»), `/setabouttext` (описание в профиле).

### 2. Узнай свой Telegram ID
Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт число. Это твой ID администратора.

### 3. Установи Python и зависимости
Нужен Python 3.11 или новее.
```bash
cd sales-bot
python3 -m venv .venv
source .venv/bin/activate        # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 4. Заполни настройки
Скопируй `.env.example` в `.env` и впиши токен и свой ID:
```
BOT_TOKEN=1234567890:AAH...
ADMIN_IDS=123456789
PAYMENT_PROVIDER=stars
```

### 5. Наполни бота
Открой `content.yaml`. Там уже собрана структура как у NIKSHEN_BOT: меню, бесплатные гайды, квиз, инструкции, вопросы, связь. Продукты, ссылки и `@ник` — заглушки, замени их на свои. Как устроены экраны — ниже.

### 6. Запусти
```bash
python -m bot
```
Открой своего бота в Telegram и нажми «Старт». Напиши ему один раз со своего аккаунта — иначе бот не сможет присылать тебе уведомления о покупках.

## Как устроены экраны

Бот — это набор экранов. Экран = текст + кнопки. `start` — главное меню.

```yaml
screens:
  start:
    text: |
      Здравствуйте, {name} 🤍
    buttons:
      - {text: "🎁 Бесплатно", screen: free}                    # одна кнопка в ряд
      - [{text: "📖 Инструкции", screen: instructions},
         {text: "❓ Вопросы", screen: faq}]                     # две кнопки в ряд
      - {text: "📘 Нейросети с нуля", product: guide}           # карточка продукта
      - {text: "🌐 Сайт", url: "https://..."}                   # внешняя ссылка ↗
      - {text: "📦 Мои покупки", my: true}
```

Чтобы добавить раздел: придумай id (латиницей), опиши экран в `screens` и поставь на него кнопку с `screen: id` в нужном месте. Не забудь кнопку «⬅️ Назад» внутри нового экрана.

Бесплатный продукт — это продукт с `free: true`: по кнопке он сразу приходит в чат, а бот считает, сколько людей его забрали.

## Бесплатные гайды

В боте 5 гайдов-PDF. Каждый решает одну задачу и в конце ведёт к платному продукту:

| № | Гайд | Для кого | Ведёт к |
|---|---|---|---|
| 01 | Первые 3 минуты с нейросетью | ещё не пользовался(ась) | гайд 02, «Нейросети с нуля» |
| 02 | Почему нейросеть отвечает водой | пробовал(а) и разочаровался(ась) | гайд 03, «Нейросети с нуля» |
| 03 | Ответ не тот: 10 поправок | ответы есть, но не те | «Библиотека запросов» |
| 04 | Бюджет поездки за 20 минут | планирует поездку | «Нейросети с нуля» |
| 05 | Неловкое сообщение за 5 минут | надо отказать, напомнить, попросить | «Нейросети с нуля», «Библиотека запросов» |

После каждого гайда бот сам присылает короткое сообщение с кнопками: следующий гайд и платный продукт (`followup` в `content.yaml`).

### Как поправить текст гайда
1. Открой нужный файл в `guides/` — это обычный текст (Markdown).
2. Поправь. Специальные блоки выглядят так:
   ```
   :::prompt Скопируй и подставь своё
   Текст запроса. [Места для своих данных] в квадратных скобках — подсветятся.
   :::
   ```
   Есть блоки `prompt`, `result`, `why`, `check`, `warn`, `note`, `bad`, `good`, `author`, `next`.
3. Пересобери PDF (нужен установленный Google Chrome):
   ```bash
   pip install markdown
   python guides/build.py
   ```
   Готовые PDF окажутся в `products/`. Отправь боту `/reload`.

Шрифты (Cormorant Garamond и Manrope, лицензия SIL Open Font) лежат в `guides/fonts/`, интернет для сборки не нужен.

## Какую оплату выбрать

| | ⭐ Telegram Stars | 💳 ЮKassa |
|---|---|---|
| Что нужно для старта | ничего, работает сразу | ИП или самозанятость + договор с ЮKassa |
| Как платит покупатель | звёздами внутри Telegram | картой или СБП на странице ЮKassa |
| Куда приходят деньги | на баланс бота в звёздах | на твой расчётный счёт в рублях |
| Правила Telegram | официальный способ для цифровых товаров | внешняя оплата по ссылке |

**Моя рекомендация:**
- **Для теста и первых продаж** — Stars: включается за минуту, можно проверить весь путь покупателя.
- **Для основной аудитории из России** — ЮKassa: люди платят привычной картой или СБП, деньги сразу в рублях.

Что важно знать честно:
- Правила Telegram требуют, чтобы цифровые товары внутри бота оплачивались звёздами. ЮKassa в этом боте работает через внешнюю страницу оплаты — так делают многие авторы, но это отступление от рекомендации Telegram. Решение за тобой.
- Вывод звёзд идёт через Fragment в криптовалюту TON и с задержкой (насколько я знаю, около 3 недель). Точные условия проверь в [правилах Telegram](https://telegram.org/tos/stars) — они меняются.
- *Предположение, не проверенный факт:* покупателям из России купить звёзды может быть сложнее, чем заплатить картой. Это может снизить конверсию.
- Насколько я знаю, ЮKassa работает с самозанятыми, но условия подключения уточни у них напрямую.
- **Чеки (54-ФЗ) бот сейчас не отправляет.** Если ЮKassa потребует передавать данные для чека, платёж не создастся. Напиши мне — добавлю.

### Подключение ЮKassa
1. Зарегистрируйся в [ЮKassa](https://yookassa.ru) и дождись одобрения магазина.
2. Личный кабинет → Интеграция → Ключи API: скопируй `shopId` и секретный ключ.
3. В `.env`:
   ```
   PAYMENT_PROVIDER=yookassa
   YOOKASSA_SHOP_ID=123456
   YOOKASSA_SECRET_KEY=live_...
   ```
4. Перезапусти бота.

Бот сам проверяет оплату каждые 30 секунд, поэтому продукт придёт, даже если покупатель забудет нажать «Я оплатил(а)».

## Продажа доступа в закрытый канал
1. Создай приватный канал и добавь бота администратором с правом **«Пригласительные ссылки»**.
2. Узнай ID канала: перешли любой пост из канала боту [@userinfobot](https://t.me/userinfobot) — ID начинается с `-100`.
3. В `content.yaml` у продукта укажи:
   ```yaml
   delivery:
     type: channel
     value: "-1001234567890"
   ```
Каждый покупатель получит одноразовую ссылку, которую нельзя переслать другу.

⚠️ При возврате денег бот **не удаляет** человека из канала автоматически — это нужно сделать вручную.

## Чтобы бот работал круглосуточно
Пока бот запущен на твоём компьютере, он работает, только когда компьютер включён. Для реальных продаж нужен сервер, который работает 24/7 — например, недорогой VPS. Когда выберешь хостинг, могу помочь его настроить.
